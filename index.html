Conectar ao GitHub

Pra excluir uma ferramenta na hora, o site precisa de um token do GitHub — é gratuito e leva ~2 minutos. Você faz isso só uma vez.

  1. Abra criar token (abre em outra aba).
  2. Em Repository access, escolha Only select repositories e marque mestres-sites-cosmos-ia.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Clique em Generate token, copie o código e cole aqui embaixo.

O token fica salvo só no seu navegador. Se outra pessoa usar este computador, ela conseguiria editar este repositório — em caso de dúvida, remova o token depois de usar.

Editar textos do site

Use *asterisco* em volta de uma palavra do título pra destacá-la. A alteração é salva no repositório e o site republica em ~1 min.
